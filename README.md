# YOLOv8 Live Object Detection

## 📌 Overview
Real-time object detection using YOLOv8 and OpenCV. The system detects objects from webcam feed with bounding boxes and FPS tracking.

## 🚀 Features
- Live webcam object detection
- YOLOv8 model integration
- FPS counter
- Fullscreen display
- Video recording support

## 🧠 Tech Stack
- Python
- OpenCV
- Ultralytics YOLOv8

## ▶️ How to Run
```bash
pip install ultralytics opencv-python
python yolo_live.py
